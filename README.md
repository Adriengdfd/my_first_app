# Desktop Fitness Tracker

Local desktop fitness tracker built with React, Vite, and Tauri.

## What it does

- manage a personal food library with calories, protein, carbs, and fat
- log meals by day using saved foods and serving counts
- define custom sport profiles with sport-specific statistics
- record activities per day and review them in a timeline
- keep data locally on the computer using browser storage inside the desktop app

## Run locally

Install dependencies and start the desktop app:

```bash
npm install
npm run tauri dev
```

## Build

```bash
npm run build
```

For a desktop bundle:

```bash
npm run tauri build
```
